Orchida UAE E-Invoicing Connector for Odoo

Odoo 19 | UAE e-invoicing interface and workflow

Orchida UAE E-Invoicing Connector for Odoo provides an Odoo interface for UAE e-invoicing workflows. This package lets teams review the connector screens, fields, menus, and invoice workflows in an Odoo 19 database before activating the full production integration.

Key Features

  • Invoice forms with UAE e-invoicing fields and status indicators.
  • Submission log views for invoice status, responses, attempts, and synchronization details.
  • Company-level e-invoicing configuration and connector settings screens.
  • Partner, journal, tax, product, and unit-of-measure workflow support screens.
  • Accounts payable invoice screens with XML and document workflow views.
  • Allowance and charge workflow screens for invoice document adjustments.

Available Screens

The module mirrors the user interface of the Orchida UAE E-Invoicing Connector across the following Odoo areas:

  • Accounting settings and company configuration.
  • Customer invoices, invoice lines, taxes, and journals.
  • Products, product templates, units of measure, and unit-code mappings.
  • E-invoice submission records and response details.
  • Orchida accounts payable invoice records and PDF report actions.
  • Document allowance and charge wizard screens.

Important: this package is for interface evaluation.

It does not send invoices to an external API, validate tax data against a service, store production credentials, build production payloads, or run submission cron jobs. Integration actions display a message directing the user to the full Orchida connector.

Installation

  1. Use the branch matching your Odoo version.
  2. Copy the module files into an Odoo addons path.
  3. Update the Apps list and install Orchida UAE E-Invoicing Connector for Odoo.
  4. Open the E-Invoicing menu to review the available screens.
