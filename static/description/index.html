What is included

  • Odoo 19-compatible trial module structure.
  • Connector-style menus, views, fields, and sample records.
  • Safe demo actions that explain the full connector requirement.
  • Standard Odoo invoice posting behavior for local evaluation.

Important: this is a UI-only trial

The trial does not call an API, submit invoices, validate tax data, store credentials, build production payloads, or run background jobs. Use the full Orchida connector for production integration.

Install in a few steps

  1. Use this module with Odoo 19.
  2. Copy the branch contents into an addons path.
  3. Update the Apps list and install Orchida UAE E-Invoicing (Trial Demo).
  4. Open the E-Invoicing menu and explore the screens.

Compatibility

Odoo 19 Community or Enterprise, with the standard base, account, and product modules installed.
